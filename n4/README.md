## Folder Structure

Each exercise is in its own folder `exercise_NN/` containing:
- `exercise.json` — structured data (questions, answers, vocabulary, media URLs)
- `exercise.md` — human-readable page text
- `question_N_audio.mp3` — audio clip for question N (listening only)
- `question_N.jpg` — question image
- transcript PDF (listening only)
